# Consignes Global Storage

- Pendant le développement d'une version non publiée, conserver le dernier numéro
  de version du dépôt publié + 1 (actuellement `0.1.4`, après `0.1.3`). Ne pas
  incrémenter le numéro à chaque modification. Regrouper les changements sous
  cette même version dans `changelog.txt`.
- Ne pas générer d'archive du mod sauf demande explicite de l'utilisateur.
- L'utilisateur réalise les tests en jeu. Ne pas lancer Factorio pour les tests ;
  les vérifications statiques restent autorisées.
